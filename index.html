Google-Synchronisierung

Für die Synchronisierung auf mehreren Geräten benötigst du die Firebase-Webkonfiguration deines Projekts. Diese Konfiguration ist für Web-Apps vorgesehen; deine Sicherheit wird über die Firestore-Regeln gewährleistet.

  1. In der Firebase Console deine Web-App öffnen und die Konfigurationswerte kopieren.
  2. Die Werte in den Konstanten am Anfang des Skripts in dieser Datei eintragen und die Datei erneut ins Repository laden.
  3. In Firebase Authentication die Anmeldung mit Google aktivieren und deine Domain unter „Authorized domains“ ergänzen.
  4. Firestore-Regeln so setzen, dass angemeldete Personen ausschließlich ihre eigenen Daten lesen und ändern können.

Erforderliche Firestore-Regeln (Firestore Console → Rules):

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}

Datenpfade: users/{uid}/expenses/{id}, users/{uid}/settings/main und users/{uid}/income/{YYYY-MM}. Die Regeln verhindern Zugriff auf Daten anderer Nutzer. Veröffentliche keine großzügigen Testregeln.

Eintrag ohne Firebase-Konfiguration: Die App funktioniert mit lokalem Browserspeicher; die Synchronisierung über Geräte ist dann nicht aktiv.
